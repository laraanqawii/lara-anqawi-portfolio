Project

Graduation project

PalCareerLink

PalCareerLink reads a graduate's CV, analyses it with spaCy and scikit-learn, and matches the candidate to relevant job postings. Companies post openings and screen applicants with qualification exams they design themselves.

Candidate profile matched to job posting

Problem

Graduates entering the job market and the companies hiring them need a way to find each other.

Solution

An AI-powered career-matching platform. NLP in Python analyses each CV and matches candidates to jobs, inside a web app that serves both applicants and companies.

My role and features

  • CV analysis and candidate-to-job matching in Python with spaCy and scikit-learn
  • Front end in JavaScript and HTML
  • Applicants create profiles, apply for jobs, and filter opportunities
  • Companies post jobs and design custom qualification exams
  • Supabase for the database, documentation, and file storage
