03

Project

Featured · Graduation project

PalCareerLink

An AI-powered career platform that reads a graduate's CV, analyzes it with NLP, and recommends relevant job postings — while giving companies their own tools to post jobs and screen applicants.

Problem

Graduates need a clearer path to openings that fit their skills, and companies need a way to find and screen suitable candidates.

Solution

A full-stack web platform that connects graduates with the job market through CV analysis and AI-driven job recommendations.

What I built

  • Implemented NLP techniques in Python (spaCy, scikit-learn) to analyze CVs and match candidates to relevant job postings
  • Built the interactive front-end using JavaScript and HTML
  • Enabled applicants to create profiles, apply for jobs, and browse filtered opportunities
  • Enabled companies to post job openings and design custom qualification exams
  • Used Supabase for database management, documentation, and file storage

Built with

  • Python
  • spaCy
  • scikit-learn
  • JavaScript
  • HTML
  • Supabase

Result

85/100 graduation project grade, Birzeit University.
